# TVMazeApp

Aplicativo React Native desenvolvido com Expo que lista séries da API pública TVmaze e mostra os episódios de cada série.

## Tecnologias

- Expo / React Native
- React Navigation Stack
- FlatList, useState e useEffect
- fetch com async/await, try/catch/finally

## Executar

```bash
npm install
npm start
```

Para abrir na versão web:

```bash
npm run web
```

## APIs

- Listagem: `https://api.tvmaze.com/shows`
- Episódios: `https://api.tvmaze.com/shows/{id}/episodes`
